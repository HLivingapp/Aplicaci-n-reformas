# App Reformas

Aplicación web y móvil para gestionar los procesos de una empresa de reformas: desde el primer contacto con el cliente hasta la entrega de la obra.

## Objetivos

- **Presupuestos**: crear presupuestos de forma rápida a partir de partidas, materiales, mano de obra y márgenes, y enviarlos al cliente para su aceptación.
- **Planificación de proyectos**: convertir un presupuesto aceptado en un proyecto con fases, tareas, plazos, equipos y proveedores.
- **Seguimiento de obra**: registrar el avance, incidencias, fotos y cambios sobre lo presupuestado.
- **Visibilidad para el cliente**: un portal donde el cliente vea el estado de su reforma, el calendario, los documentos y las fotos, y pueda aprobar cambios.
- **Procesos internos**: reflejar el flujo de trabajo propio de la empresa (captación, visita, presupuesto, contrato, ejecución, entrega y postventa).

## Plataformas

- Aplicación web (gestión interna y portal de cliente).
- Aplicación móvil (equipo en obra y clientes).
